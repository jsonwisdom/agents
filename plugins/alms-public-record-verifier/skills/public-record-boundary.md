# Public Record Boundary

Use this skill when reviewing claims based on filings, registries, court records, agency records, benefit records, public databases, sanctions lists, licenses, property records, corporate records, or civic records.

## Required evidence by claim

| Claim | Required evidence |
|---|---|
| record exists | source name, retrieval path, date observed |
| filing exists | filing ID or docket/reference number |
| case status | court/source page and date observed |
| license status | agency source and record identifier |
| property record | jurisdiction source and parcel/record ID |
| corporate registration | registry source and entity ID |
| benefit eligibility | explicit agency determination, not inference |
| identity match | more than name similarity; source-supported identifiers |

## Unsafe promotions

- record observed -> truth proven
- filing observed -> guilt proven
- complaint observed -> misconduct proven
- denial observed -> ineligibility proven forever
- name match -> identity proven
- stale record -> current status
- public mention -> official determination

## Safe language

Use:

- observed in public record
- source reports
- record states
- as of date observed
- source does not establish
- claim exceeds cited record
- authority=false

## Rule

A public record can support only the field it visibly reports.

It cannot, by itself, establish intent, guilt, full identity, eligibility, entitlement, ownership, fraud, or legal conclusion unless the cited source explicitly states that conclusion.
