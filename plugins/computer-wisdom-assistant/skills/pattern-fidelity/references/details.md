# Pattern fidelity — presentation analogue and refusals

Use this file when a teaching, named story, ENS label, or "mission" language appears next to a GitHub task. The skill body is the fence. This file is extra classification, not extra authority.

## STORY_FORM is presentation, not evidence

A teaching presentation can *illustrate* a governance analogue that already exists in this plugin (wait-for-send, honor HOLD, labor ≠ brains, small bounded change). Illustration is not a source.

```text
story_form=PRESENTATION
facts_promoted=0
edges_inferred=0
silent_inference=BLOCKED
authority_created=false
```

Do not treat the presentation as:

- evidence
- a GitHub workflow
- Digger
- a BoxDee audit
- family-graph edges
- cryptographic proof that a label is a person
- ecclesiastical, legal, or governmental authority

If a later session needs a fact, it must come from an inspectable locator via `skills/evidence-first-judgment`. A story never becomes that locator by being copied into this repo.

## Presentation citations (not source evidence)

The operator may paste a long teaching that uses names such as Barnabas, Antioch, or "Player 001." Those names are **story furniture**. Cite them only as presentation, never as proof, identity, or mandate.

```text
Presentation (not evidence):
- Named story beats were used to *label* analogue rows already in
  bounded-authority, complexity-budget, and replayable-reasoning.
- No row in those skills gained new rights because a story was attached.
- GitHub apply is a code artifact of the pattern, not ministry.
```

Do not implement spiritual practice options (notebook, message a believer, worship in a hard relationship, study a biblical book) as repo work. Those belong to the human operator. This plugin records engineering fences only.

Do not create an agent that speaks as an apostle, claims the Spirit, wears a halo, or treats church as CI. Prefer this skill. If an agent file is ever added, it must use a plugin-scoped `name` so it cannot overwrite another plugin's agent.

## Analogue rows (expanded)

### Wait to be sent

Self-appointment is a boundary failure. Labor waits for an **exact operator send** (`skills/bounded-authority`). A previous yes to a different action is not this send. "The topic matters" is not a send.

### Ambassadors, not owners

In-scope labor may inspect, recommend, and (when the send names the mutation) edit the named paths. Labor does not become brains. Jason is the brains. Jay is the labor. Mission creep is a new bound, not an extension of this one.

### Honor closed doors

`HOLD` and `BLOCKED` are successful honesty. Forced outcomes, retry-until-green, and invented receipts are defects. No fake green.

### No status

Default remains `authority=false`. This skill does not create authority. Weakness here means: no rank, no certification, no speaking as owner.

### Morning assignment / evening log

The useful log is replayable locators (paths, SHAs, run IDs), not a performance narrative. If the turn cannot be replayed from artifacts, mark `documentation-only` or `BLOCKED` (`skills/replayable-reasoning`).

### Small bounded change

Pattern fidelity is a complexity-budget choice: one companion skill under an existing plugin beats a new marketplace plugin, a new persona, or a graph rewrite (`skills/complexity-budget`).
