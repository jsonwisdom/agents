# Length, threads, and unsafe publish patterns

## Length

A single X post is 280 characters. If the draft is longer, split a thread and show every post's exact text in the gate. One approval covers only the texts shown.

## Threads

Number each post. Do not hide later posts behind "etc."

```text
1/ ...
2/ ...
```

## Unsafe publish patterns

- posting from a connected account "to test"
- reply storms or automated engagement
- pasting secrets, tokens, or private URLs
- quoting someone as endorsement without the locator
- deleting without a gate (delete is also publication-shaped: it changes the public record)

## After a send

If a publish actually happens, record:

```text
locator: post URL or id
account:
timestamp if visible
authority=false
role=labor
brains=Jason
```

A send without that locator is not a success claim. It is `PASS_WITH_NOTES` at best.

## Pairing

Unverified world-claims in a draft belong with `skills/x-read-evidence` (the tweet will not become the receipt).
